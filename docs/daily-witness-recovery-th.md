# ตรวจหลักฐานแถวรายวันที่ค้าง REVIEW

ส่วนนี้เป็น candidate ที่ปิดค่าเริ่มต้น ยังไม่อนุญาตให้เปิดใช้งาน production ก่อนตรวจ migration, สิทธิ์, การระบาย Worker รุ่นเก่าและคำขอ Google ที่ค้าง และแนวทางปลด REVIEW ทั้งระบบ

`POST /admin/daily-recovery/inspect` ใช้ตรวจหลักฐานปัจจุบันโดยไม่ส่งค่าในแถวกลับ ผู้ดูแลต้องหยุดการแก้ชีตชั่วคราวและตรวจให้แน่ใจว่า Worker เดิมรวมถึงคำขอที่ส่งไปแล้วสิ้นสุดก่อนดำเนินการต่อ การระบุ `editorsPaused` และ `legacyWritersDrained` เป็นคำรับรองของผู้ดูแล ไม่ใช่หลักฐานทางเทคนิคว่าไม่มีใครแก้หรือไม่มีคำขอค้าง

เมื่อหลักฐาน postimage ตรงและ source ยังคงเดิม `POST /admin/daily-recovery/advance-witness` ใช้ action ID ที่กำหนดล่วงหน้าและ evidence digest จากผล inspect เพื่อบันทึก witness รุ่นใหม่และ audit ในธุรกรรม D1 เดียว การดำเนินการนี้อ่านชีตอย่างเดียว ไม่ส่งคำขอเขียน Google ซ้ำ และ **ยังคงสถานะ REVIEW กับตัวล็อกไว้** ไม่ได้เปิดให้ซิงก์ต่อหรือปิดงานทั้งสามส่วน

หากผลตอบกลับหาย ให้ตรวจ `POST /admin/daily-recovery/witness-status` ด้วย action ID เดิม สถานะ `NOT_FOUND_OR_UNCERTAIN` ไม่ใช่หลักฐานว่าไม่มีธุรกรรมเกิดขึ้นและไม่อนุญาตให้ส่งซ้ำเอง ต้องตรวจสอบโดยผู้ดูแลก่อนดำเนินการต่อ

การอ่านข้อมูลและการบันทึก D1 ไม่ใช่การเขียนแบบมีเงื่อนไขบน Google Sheets ผู้แก้ชีตหรือคำขอเก่าอาจเปลี่ยนข้อมูลหลังอ่านได้ แม้เปิดตัวเลือกนี้แล้วก็ต้องคง gate รายวันปิดไว้จนมีกระบวนการปลด REVIEW และระบบซิงก์ครบถ้วนที่ผ่านการตรวจ
