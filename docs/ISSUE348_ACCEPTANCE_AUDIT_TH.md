## หลักฐานที่ใช้รับช่วง

`RECOVER_ROUND` อ่านรอบเดิม ไม่สั่งปิด: ถ้ายัง OPEN ให้หยุดกระทบยอด เพราะ close เดิมอาจยังค้าง. เริ่มจาก `READ`/`LIST_RECENT` เพื่อดู round และ snapshot; ดู audit, epoch, job, claim และ journal ที่ระบุงานและรุ่นก่อนตัดสินใจ. สถานะ claim ที่แสดงเป็นของทั้งไฟล์และอาจเป็นของงานอื่น. `READ_HISTORICAL`/`READ_ROUND` เป็นการอ่านย้อนหลังเท่านั้น ไม่ใช่ proof ว่าชีตปัจจุบันตรงหรือสิทธิ์จองต่อ; หากไม่มี snapshot หรือหลักฐานขัดกันให้ RECONCILE. `CLOSE_MOCK_ROUND` รับเฉพาะ localhost + flag จำลอง และ Worker ต้องเป็น `APP_ENV=test`; รอบ OPEN ต้องมี coordinator จำลองยืนยัน quiescence ผูก round/รุ่น/fence/nonce ก่อนส่ง ส่วน CLI ปกติไม่มี coordinator; เมื่อคำตอบหาย runner อ่านรอบเดิมโดยไม่ส่งคำสั่งซ้ำ.

หลังรวม test gate รูปจริงเข้ากับ branch: `npm run check` ที่ `f28329a` ได้ 2,597 ผ่าน / 6 ล้ม / 0 ข้าม จาก 2,603; หกข้อเป็น live prerequisites ที่ยังขาดตาม [handoff](LIVE_TEST_INPUTS_HANDOFF_TH.md), ไม่ใช่ผลอ่านภาพจริง. `wrangler deploy --dry-run` ผ่าน. ผล 2,597/0/6 ในตารางเป็นก่อนรวม test gate และเก็บไว้เป็นหลักฐานตามเวลาตรวจ.
