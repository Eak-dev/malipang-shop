# Prototype: ตรวจรหัสรายการใน RAW และรายละเอียด (ยังไม่ใช่ระบบซิงก์ใหม่)

สถานะ: ทดลองเท่านั้น ปิดโดยค่าเริ่มต้น ห้ามใช้เป็นหลักฐานสำหรับ deploy หรือบอกว่างานนี้แก้แถวผิดใน production แล้ว

เมื่อ `SHEETS_LEDGER_IDENTITY_INSPECTION=true` งาน EXPENSE/PERSONAL_USE และ purchase detail จะอ่านรหัสในชีตปัจจุบัน โดยไม่อ่าน `sheet_row_index` และพักเป็น REVIEW ก่อนจอง/เขียนแถวเสมอ การตรวจพบหนึ่งรายการไม่ได้อนุญาตเขียน เพราะผู้ใช้สามารถย้าย ลบ หรือคัดลอกแถวระหว่างอ่านกับเขียนได้ เมื่อไม่ตั้งค่า flag เส้นทางเดิมไม่เปลี่ยนและยังมีความเสี่ยงเดิม

RAW ใช้ Expense_ID และ Personal_Use_ID ในคอลัมน์ A; purchase detail ใช้ Purchase_Item_ID คอลัมน์ A ร่วม Expense_ID คอลัมน์ B. Snapshot ต้องครอบคลุมขนาด grid จริง ไม่เกิน 10,000 แถว และหัวตารางต้องตรง; ไม่พบ, พบซ้ำ, ข้อมูลไม่ครบ, grid ใหญ่เกินหรืออ่านไม่ได้ ต้อง REVIEW และไม่บันทึกข้อมูลส่วนตัวลงข้อความเหตุผล. ค่าตรงเพียงรายการเดียวเป็นเพียงหลักฐาน ณ เวลาที่อ่าน ไม่ใช่การรับรองเอกลักษณ์หรืออนุญาตแก้ไข.

ก่อนเปลี่ยนเป็นระบบใช้งานจริง ต้องมีวิธีเขียนโดยอ้างอิง identity ที่เคลื่อนตามแถวแทน A1 snapshot, จัดการ sort เฉพาะคอลัมน์/duplicate/copy, race กับผู้ใช้และ worker เก่า, การค้นหาเมื่อข้อมูลย้าย/หาย, operation ที่ผลลัพธ์ไม่แน่ชัด, safe append และการ recover โดยไม่สร้างรายการซ้ำ พร้อมทดสอบ Google Sheets จริงบนสำเนาและแผน cutover/reconcile. ระบบจริงยังไม่มีการเปิด flag หรือแก้ configuration.

มีต้นแบบ request `values.batchUpdateByDataFilter` ที่ชี้ด้วย metadata ID เฉพาะแถวแทนเลขแถว โดยรักษาคอลัมน์ ID และระบุเฉพาะ field ที่ตั้งใจแก้: ทุก field ต้องตรง preimage ที่เชื่อถือได้ และจะพักหากมีสูตร, note, validation, preimage ไม่ครบหรือมีการแก้โดยผู้ใช้ การยกเลิก detail แก้เฉพาะสถานะ/เวลา ตัวทดลองยัง **ไม่เชื่อมกับเส้นทางซิงก์**, ถูกปิดด้วยค่าเริ่มต้น, ไม่มีขั้นตอนติด metadata ให้รายการเดิมหรือเพิ่มรายการใหม่ และทดสอบกับ mock ไม่ใช่ Google Sheets จริง. Metadata จะตามการย้ายแถวทั้งแถว แต่ผู้ใช้ยังสามารถ sort เฉพาะบางคอลัมน์หลังตรวจข้อมูลทำให้ข้อมูลกับ metadata ไม่ตรงกันได้. ห้ามเปิด `SHEETS_LEDGER_ANCHORED_WRITE_PROTOTYPE` ใน production จนมี cutover ที่กัน writer เก่าและมีวิธีตรวจสอบ identity ที่รับมือ concurrent edits ได้จริง.
